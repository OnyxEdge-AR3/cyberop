# CyberOP (installable app)

1. Create a GitHub repo named `cyberop` (public) and upload every file in this folder to it.
2. Repo Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
3. After a minute, open https://YOUR-USERNAME.github.io/cyberop/
   - Android (Chrome): menu ⋮ → Install app.
   - Desktop (Chrome or Edge): install icon at the right of the address bar.
4. In the app: Settings → paste your Anthropic API key → Test connection.
5. Settings → Sync phone and desktop → paste a GitHub classic token with only the `gist` scope. Repeat 4–5 on each device.

To update the app later, replace index.html and sw.js in the repo.
